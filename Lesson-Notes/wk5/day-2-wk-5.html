Arrays, Objects & JSON Data

1. Theory: The Big Picture

In Session 13, we explored control flow structures and functions to process decision logic and iterate through datasets. However, real-world software applications do not manage isolated primitive variables; they handle rich, structured entities. In our Agile Task Board project, a task is never just a simple string—it is a composite entity containing an ID, title, description, priority status, category tag, and assignee details. Furthermore, these individual tasks exist collectively within organized collections or lists.

Mastering Objects, Arrays, and JSON (JavaScript Object Notation) is fundamental to full-stack engineering. Objects model complex real-world entities using key-value pairs, arrays manage ordered lists of those entities, and JSON acts as the universal data serialization format bridging our client-side JavaScript interface with our Python FastAPI backend databases.

2. Theory: Technical Standards & Data Structures

2.1 Object Literals and Key-Value Structures

An object is a collection of related data and functionality stored as key-value pairs. Keys (properties) are strings (or symbols), while values can be primitives, arrays, nested objects, or functions (methods).

/* Object Literal Definition */
const taskItem = {
  id: 101,
  title: "Implement JWT Authentication",
  category: "backend",
  priority: "high",
  isCompleted: false,
  metadata: {
    author: "Chibuzor Kanu",
    estimatedHours: 6
  },
  getSummary() {
    return `${this.title} [${this.priority.toUpperCase()}]`;
  }
};

// Property Access: Dot Notation vs Bracket Notation
console.log(taskItem.title);          // "Implement JWT Authentication"
console.log(taskItem["category"]);      // "backend"

2.2 Array Mutation Methods

Arrays in JavaScript are ordered lists of data items. To manage dynamic lists (such as adding, removing, or reordering tasks on our Kanban board), JavaScript provides powerful array methods:

Method Operation Type Description & Behavior
push() Mutating (End) Appends one or more elements to the end of an array and returns the new length.
pop() Mutating (End) Removes the last element from an array and returns that removed element.
unshift() Mutating (Start) Adds one or more elements to the beginning of an array.
shift() Mutating (Start) Removes the first element from an array and returns it.
splice() Mutating (Anywhere) Adds, removes, or replaces elements at a specified index (e.g., `array.splice(index, 1)` deletes 1 item).

2.3 JSON Serialization and Deserialization

JavaScript Object Notation (JSON) is a lightweight, text-based data interchange format derived from JavaScript object syntax. Because networks and storage mechanisms (like `localStorage` or HTTP response bodies) cannot transmit live JavaScript memory objects directly, data must be serialized into a JSON string and deserialized back into objects.

  • JSON.stringify(value): Converts a JavaScript object or array into a JSON-formatted string.
  • JSON.parse(text): Parses a JSON-formatted string and reconstructs it into a live JavaScript object or array.
/* JSON Serialization & Deserialization Workflow */
const activeBoardState = [{ id: 1, title: "Refactor CSS", status: "todo" }];

// Serialize to JSON string for storage or network transport
const jsonString = JSON.stringify(activeBoardState);
console.log(jsonString); // '[{"id":1,"title":"Refactor CSS","status":"todo"}]'

// Deserialize back into live JavaScript array
const restoredState = JSON.parse(jsonString);
console.log(restoredState[0].title); // "Refactor CSS"

We will now write an advanced task state manager in js/app.js utilizing object literals, array mutation methods (`push`, `splice`), and JSON serialization to simulate persistent task board operations.

Step 1: Add Object & Array State Manager to `js/app.js`

Open js/app.js and append the following comprehensive state management module:

/* ==========================================================================
   AGILE TASK BOARD - ARRAYS, OBJECTS & JSON STATE MANAGER (Session 14)
   ========================================================================== */

// 1. Task Board State Management Object
const kanbanTaskManager = {
  boardName: "Sprint 14 Core Board",
  tasks: [
    { id: 301, title: "Design PostgreSQL ERD", category: "database", priority: "high", status: "todo" },
    { id: 302, title: "Build FastAPI Endpoints", category: "backend", priority: "medium", status: "in_progress" }
  ],

  // Method to add a new task object to the array (Mutation: push)
  addNewTask(title, category, priority, status = "todo") {
    const newTask = {
      id: Date.now(), // Unique numeric timestamp ID
      title: title.trim(),
      category: category,
      priority: priority,
      status: status
    };

    this.tasks.push(newTask);
    console.log(`%c[Success] Task added: "${newTask.title}"`, "color: #10b981; font-weight: bold;");
    this.syncToStorage();
    return newTask;
  },

  // Method to delete a task by ID using array searching and splice mutation
  deleteTaskById(taskId) {
    const index = this.tasks.findIndex(task => task.id === taskId);
    
    if (index !== -1) {
      const removedTask = this.tasks.splice(index, 1)[0];
      console.log(`%c[Deleted] Task removed: "${removedTask.title}"`, "color: #ef4444; font-weight: bold;");
      this.syncToStorage();
      return true;
    }
    
    console.warn(`[Warning] Task ID ${taskId} not found for deletion.`);
    return false;
  },

  // Method to serialize state to JSON string and save to localStorage simulation
  syncToStorage() {
    const serializedData = JSON.stringify(this.tasks);
    localStorage.setItem("kanban_tasks_backup", serializedData);
    console.log("%c[Storage] Board state serialized and synchronized.", "color: #2563eb;");
  },

  // Method to load and deserialize state from JSON storage
  loadFromStorage() {
    const rawData = localStorage.getItem("kanban_tasks_backup");
    if (rawData) {
      this.tasks = JSON.parse(rawData);
      console.log("%c[Storage] Board state restored from JSON payload.", "color: #8b5cf6; font-weight: bold;");
    }
  }
};

// 2. Execution & Console Verification
console.group("%c📦 Agile Task Board - State Manager Test", "color: #2563eb; font-weight: bold; font-size: 13px;");

// Test adding a task
kanbanTaskManager.addNewTask("Configure Alembic Migrations", "database", "high", "todo");

// Display current task list in tabular format
console.table(kanbanTaskManager.tasks);

// Test JSON serialization output directly
const exportedJsonPayload = JSON.stringify(kanbanTaskManager.tasks, null, 2);
console.log("Exported JSON Payload String:\n", exportedJsonPayload);

console.groupEnd();

Step 2: Architectural Walkthrough & Debugging Notes

  1. Method Context (`this`): Inside the `kanbanTaskManager` object, using `this.tasks` ensures the methods operate directly on the object's internal array state.
  2. Using `splice()` for Deletions: `findIndex()` locates the exact numeric array index of the target task ID, and `splice(index, 1)` cleanly extracts and removes that single object from the array without leaving empty `undefined` slots (unlike the `delete` operator).

/* Classwork Solution: Object Method for Status Updates */

// Add this method inside the kanbanTaskManager object definition:
kanbanTaskManager.updateTaskStatus = function(taskId, newStatus) {
  const targetTask = this.tasks.find(task => task.id === taskId);

  if (targetTask) {
    targetTask.status = newStatus;
    console.log(`%c[Updated] Task #${taskId} status changed to "${newStatus}"`, "color: #d97706; font-weight: bold;");
    this.syncToStorage();
    return true;
  }

  console.error(`[Error] Task ID ${taskId} could not be found for status update.`);
  return false;
};
