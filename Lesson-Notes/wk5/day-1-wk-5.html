2. Theory: Control Flow & Function Architecture

2.1 Conditional Branching: `if/else` and `switch`

Conditional statements allow your program to execute different blocks of code depending on whether a boolean expression evaluates to true or false.

  • `if / else if / else` Statements: Ideal for evaluating complex ranges, multiple independent variables, or compound boolean logic (using `&&` and `||`).
  • `switch` Statements: Designed for evaluating a single expression against multiple discrete matching cases. It utilizes `break` statements to prevent fall-through execution bugs.
/* Switch Statement Example: Task Priority Badge Dispatcher */
function getPriorityBadgeClass(priorityLevel) {
  switch (priorityLevel) {
    case 'high':
      return 'badge-danger';
    case 'medium':
      return 'badge-warning';
    case 'low':
      return 'badge-success';
    default:
      return 'badge-secondary';
  }
}

2.2 Iteration and Loops: `for` and `while`

When processing collections of data—such as iterating through our Kanban board task list—loops automate repetitive execution.

  • `for` Loop: The standard counter-controlled loop, perfect when you need precise control over the index iteration sequence (`for (let i = 0; i < array.length; i++)`).
  • `for...of` Loop: A modern, readable ES6 loop specifically engineered for iterating directly over iterable objects like arrays.
  • `while` Loop: Executes a block of code repeatedly as long as a specified condition evaluates to true. Use with caution to avoid infinite loop locks.

2.3 Traditional Functions vs. ES6 Arrow Functions

JavaScript supports multiple ways to declare functions. Understanding their structural and semantic differences is critical for professional software engineering:

Feature Traditional Function Declarations ES6 Arrow Functions (`=>`)
Syntax function calculate(a, b) { return a + b; } const calculate = (a, b) => a + b;
Hoisting Hoisted: Can be called before its definition line in the code. Not Hoisted: Must be declared before invocation.
`this` Binding Has its own dynamic this context based on how it is called. Lexical this: Inherits this from the surrounding enclosing scope.

// 2. ES6 Arrow Function for Priority Filtering (Implicit Return)
const filterTasksByPriority = (tasksArray, targetPriority) => {
  const filteredResults = [];
  
  // Traditional for...of loop for iteration
  for (const task of tasksArray) {
    if (task.priority === targetPriority) {
      filteredResults.push(task);
    }
  }
  
  return filteredResults;
};

// 3. Conditional Metric Counter Function using If/Else branches
function calculateBoardMetrics(tasksArray) {
  let highPriorityCount = 0;
  let completedCount = 0;
  let activeCount = 0;

  for (let i = 0; i < tasksArray.length; i++) {
    const currentTask = tasksArray[i];

    if (currentTask.priority === "high") {
      highPriorityCount++;
    }

    if (currentTask.status === "done") {
      completedCount++;
    } else {
      activeCount++;
    }
  }

  return {
    total: tasksArray.length,
    highPriority: highPriorityCount,
    completed: completedCount,
    active: activeCount
  };
}

Solution Code

/* Classwork Solution: Keyword Search Arrow Function */
const searchTasksByKeyword = (tasksArray, keyword) => {
  const matches = [];
  const normalizedKeyword = keyword.toLowerCase();

  for (const task of tasksArray) {
    const normalizedTitle = task.title.toLowerCase();
    
    if (normalizedTitle.includes(normalizedKeyword)) {
      matches.push(task);
    }
  }

  return matches;
};
